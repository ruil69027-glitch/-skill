# 便利贴解构风格海报 Skill

## 目标

将用户提供的产品图片制作成适合小红书、Instagram 等平台发布的便利贴解构风格海报。

海报应当以产品为主体，结合便利贴、纸张、胶带、杂志剪贴和生活方式摄影元素，形成低饱和、柔和、具有编辑感的视觉效果。

必须尽量保留产品的真实外观，包括：

- 产品颜色
- 产品形状
- 产品数量
- 产品上的品牌标识
- 产品的主要材质和纹理

## 输入分析

开始制作前，先识别用户提供的内容：

- 产品主体和产品数量
- 产品的颜色、形状、材质和纹理
- 图片中的品牌标识和已有文字
- 用户指定的标题、卖点、平台和画幅
- 用户指定的风格、色彩和氛围

如果用户没有提供标题、平台或尺寸，不要反复追问，使用默认参数继续完成第一版。

如果用户没有提供文案或海报所需文字，进入“自动提炼文案”模式：

- 根据图片中实际可见的产品主体、颜色、纹理、材质、形状和场景，梳理出 2—4 个视觉重点。
- 将视觉重点转化为简短、适合便利贴呈现的文案，例如质感描述、氛围描述、颜色描述或生活方式表达。
- 默认生成 1 条主标题和 2—4 条便利贴短句；短句应简洁，避免长段落。
- AI 自动生成的主标题和便利贴短句默认使用简体中文，不得默认生成英文。
- 只有用户明确要求英文或中英双语时，才使用对应语言；产品包装、Logo 或图片中原本存在的英文保持原样，因为它们属于产品原文。
- 只使用图片能够支持的信息，不臆造品牌、功能、规格、成分、功效或未经证实的产品卖点。
- 如果某项信息无法从图片确认，使用中性的感受型表达，或不写入文案。

## 触发后的首次确认

每次 Skill 被触发并收到产品图片后，在开始生成前先向用户询问一次：

> 这次海报的文案需要修改吗？还有其他需要调整的地方吗？如果没有，我将根据图片自动提炼文案，并沿用已确认的标准母版。

如果用户回答“没有”“不用”或类似意思，直接进入自动提炼文案和生成流程，不再重复追问。

如果用户提出了文案、颜色、构图或其他修改，记录这些要求并在本次生成中执行。若用户在首次消息中已经写明修改内容，只需确认是否还有其他修改，不要重复询问已经明确的内容。

## 默认参数

当用户没有特别要求时，使用以下默认设置：

- 画幅：3:4 竖版
- 发布平台：小红书或 Instagram
- 背景：米白、浅灰或低饱和奶油色
- 视觉元素：便利贴、纸张、胶带、杂志剪贴
- 光线：柔和自然光
- 氛围：安静、温柔、简洁、具有生活方式杂志感

## 标准母版与一致性模式

标准母版位于 `assets/master-poster.png`，已经由用户确认。除非用户明确要求更换母版，否则不得重新设计或替换这张标准母版。当用户要求批量制作、统一风格、版式一致或“每张都一样”时，优先将这张母版作为版式和视觉参考。母版中的英文只作为版式和字体风格参考，不作为新海报文案；新海报自动生成的文案仍默认使用简体中文。

锁定以下内容：

- 3:4 竖版画布
- 上方主标题纸张的位置和比例
- 左侧主便利贴、右侧两张便利贴的位置和大小
- 左下角产品纹理切片的位置
- 产品主体的中央偏下区域
- 背景的米白、浅灰和低饱和粉色拼贴关系
- 胶带、纸张边缘、留白和整体光影方向

批量生成时只替换产品主体和自动提炼的文案，不重新设计背景、装饰元素或版式。需要完全一致时，优先采用固定母版合成；图像生成只用于产品主体变化或必要的局部调整。

## 制作流程

按照以下顺序完成任务：

### 0. 首次确认修改需求

触发 Skill 后，先完成一次文案和其他修改需求确认，再开始生成。确认完成后，不要因为信息不完整而连续询问多个问题；缺少的内容按默认参数和自动提炼文案规则处理。

### 1. 分析产品图

先确认产品主体、数量、颜色、形状、材质、纹理和品牌标识。产品是画面的核心，不要让装饰元素遮挡产品的关键部分。

### 2. 确定海报方向

根据用户提供的标题、卖点和风格要求，确定：

- 画面主标题
- 产品在画面中的位置和大小
- 便利贴、纸张和剪贴元素的位置
- 背景色和整体色彩关系
- 光线、阴影和空间层次

如果用户没有提供文案，先完成“自动提炼文案”，再把主标题放在主视觉区域，把 2—4 条短句分别放在便利贴或纸张元素上。

### 3. 组织生成要求

将产品信息、构图、视觉风格、文字内容和画幅比例组织成一份完整的图像生成要求，再调用图像生成工具。

如果启用一致性模式，必须明确说明“以 `assets/master-poster.png` 为版式参考”，并锁定母版中的元素位置和比例。

生成要求中要明确说明：

- 产品需要保持真实、清晰、完整
- 画面需要有便利贴解构和纸张拼贴感
- 文字要简洁、清楚；自动生成的主标题和便利贴短句默认使用简体中文，并且必须与图片中可见的产品特征一致
- 产品包装、Logo 和原图中已有的英文或其他文字属于产品原文，应尽量保留，不要把它们误改成自动文案
- 便利贴上的文字优先使用自动提炼出的短句，不要添加用户没有要求且图片无法支持的宣传承诺
- 避免大段文字、复杂说明和无意义乱码
- 不要凭空增加多个不同版本的产品

### 4. 检查生成结果

生成后检查以下内容：

- 产品是否仍然容易辨认
- 产品数量和主要结构是否正确
- 产品颜色和材质是否被错误改变
- 标题是否清楚、完整
- 自动生成的文案是否确实来自图片可见信息，是否使用了简体中文，是否存在夸大或臆造内容
- 是否出现乱码、重复产品或畸形物体
- 画面是否适合指定的平台和比例

### 5. 交付第一版

向用户展示生成的海报，并用一句话说明本版的视觉方向。不要输出冗长的技术过程。

## 修改规则

用户提出修改时，只调整用户明确指出的部分，并尽量保留已经确认的产品、构图和视觉方向。

常见修改方式：

- 用户说“换标题”：只修改标题和相关文字，不改变产品和整体构图。
- 用户说“换背景”：只修改背景颜色、背景纹理或环境，不改变产品主体。
- 用户说“去掉便利贴”：移除便利贴元素，保留产品位置和整体氛围。
- 用户说“更温柔”：降低对比度，使用更柔和的光线和颜色，不改变产品结构。
- 用户说“更高级”：减少装饰元素，强化留白、材质、光影和版式秩序。
- 用户说“更有杂志感”：加强编辑式构图、标题排版和纸张层次。
- 用户没有提供文案或图片文字时：自动识别图片重点，重新生成主标题和便利贴短句；文案只基于图片可见信息，不臆造产品功能或功效。
- 用户没有指出具体修改部分时，先根据反馈判断最相关的视觉元素，必要时简短确认。

每次修改后，重新检查产品外观、文字清晰度和画面比例。
